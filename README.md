# Тёмная тема для Redmine

Расширение для локального пилота в Chrome и Edge. Тема применяется на `https://project.simplex48.ru/`. Настройка сохраняется локально в профиле браузера.

## Установка

1. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
2. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
3. Выберите папку `extension` из этого проекта.
4. Откройте Redmine. Если вкладка уже была открыта до установки или обновления расширения, обновите её один раз.
5. Нажмите иконку расширения в меню браузера и включите «Тёмная тема». Для быстрого доступа закрепите иконку на панели.

После первоначальной загрузки переключатель меняет тему сразу во всех открытых вкладках Redmine. При первой установке тема выключена.

## Проверка пилота

- В каждом браузере откройте две вкладки Redmine и любую страницу другого сайта. Включите и выключите тему и проверьте обе вкладки Redmine. Откройте новую вкладку Redmine и перезапустите браузер с включённой темой, чтобы проверить сохранение настройки.
- После входа проверьте список задач и фильтры, карточку задачи с чек-листом, форму редактирования и всплывающие меню. Проверьте читаемость статусов, текста и фокуса при навигации клавишей Tab. Выключите тему и сравните со штатным оформлением.
